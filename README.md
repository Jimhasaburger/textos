# how to run
## minimum requirements:
- architecture: x86 (i386 or higher)
- boot: BIOS or UEFI with Legacy/CSM support
- Ram: 4 MB
- display: VGA text mode compatible

## virtualbox
- create a new vm
- name it whatever you want
- select the ISO image
- make it other/unknown (NOT 64 BIT!)
- any specs will work, defaults are best.
- disk also doesnt matter
- press finish
- press start on vm
- if there are errors, report to issues tab
